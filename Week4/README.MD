## Use Case Diagram Description

### Money Exchange System - Use Case Diagram

The above use case diagram shows some important functionalities of the **Money Exchange System** and how users use the application. The diagram indicates how the two main actors, namely **Admin/User**, **Customer** and system modules such as customer management, currency management, transaction management, and payment management work together.

---

### Purpose of the Diagram

In this diagram, we intend to show the functionalities of the system and how users interact with the software application. By doing this, we will be able to define the requirements of the system and understand what functions the application performs.

---

## Actors

### 1. Admin/User

The Admin/User is an actor that can execute most of the actions provided by the application and perform most operations in the system. The admin can add, update and view the records related to customers, currencies, transactions, and payments.

### 2. Customer

The Customer is an actor that is involved in transactions and payments. In this system, customers can view transaction and payment records.

---

# Functional Modules

## 1. Customer Management

This module is in charge of handling customer data.

### Use Cases:

* **Add Customer** - This use case lets you record customers' details to the system
* **View Customer** - This use case is about viewing customer details
* **Update Customer** - This use case allows you to update the records of customers

---

## 2. Currency Management

This module handles currency-based operations.

### Use Cases:

* **Add Currency** - With this use case, you can add supported currencies and exchange rate data
* **View Currencies** - In this use case, you can see all currencies available in your system

---

## 3. Transaction Management

This module is used for money exchange operations and transactions.

### Use Cases:

* **Add Transaction** - This use case allows adding the money exchange transaction records to the system
* **View Transaction** - With this use case, you can see transactions

---

## 4. Payment Management

This module deals with the handling of payments.

### Use Cases:

* **Add Payment** - Add a record of payment to the database
* **View Payment** - This use case lets you view payment records

---
