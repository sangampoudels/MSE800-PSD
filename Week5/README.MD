The Finance Money Exchange Application is an online application, through which the customer can exchange currencies in a safe way with each other, in accordance with the currency exchange rates provided in the application. The application offers users the opportunity to register, log in, select the currency, calculate the amount, process payment and manage their transaction history.
In this system, Customer registers and logs in to the application as a first step. Once authenticated, the customer chooses the currencies to be exchanged, inputs the quantity to be converted and the system processes the inputted quantity with the stored exchange rates in the application database to get the converted amount. The customer will then approve the transaction and make the payment via the built-in payment process. Payment is successfully made, then the system will print out a receipt of the transaction and save the transaction details as a record for further use.
The customer will also be able to check the previous transactions and edit the beneficiary's information for future transactions.
The Administrator will handle user, currency, exchange rate and financial report aspects of the system. The application does not use an external exchange rate provider, but the administrator manually updates exchanges rates.
This application covers:The user is identified and authenticated.The user registers and logs in.Currency exchange transactions,Exchange rate management,Payment confirmation,Transaction history management,Beneficiary management,Administrative reporting and monitoring.
